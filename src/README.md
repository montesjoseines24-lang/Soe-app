# 💻 Código Fuente

Estructura de carpetas en `/src`:

```
src/
├── components/          # Componentes React
├── utils/               # Funciones utilitarias
├── data/                # Datos y JSON
├── App.jsx
├── index.js
└── index.css
```

---

## 📁 Carpetas

**components/** - Componentes React reutilizables
**utils/** - Funciones de lógica
**data/** - Archivos JSON y datos estáticos
