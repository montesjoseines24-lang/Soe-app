# 🐺 SOE - Hombres Lobo TikTok

**Generador de Ideas, Guiones y Estrategia de Videos para TikTok**

---

## 🎯 ¿Qué es SOE?

SOE es tu **sistema operativo completo** para:
- ✅ Generar 100+ ideas de videos automáticamente
- ✅ Crear guiones con IA
- ✅ Trackear rendimiento de tus videos
- ✅ Exportar datos y reportes
- ✅ Compartir con tu equipo

**Todo gratis. Todo funcional. Todo organizado.**

## 🚀 Inicio Rápido

### Opción 1: Sin instalar (5 min)
```bash
# Ve a: https://codesandbox.io/s/react
# Copia: src/App.jsx → App.js
# ¡Genera ideas!
```

### Opción 2: En tu PC
```bash
# Clona
git clone https://github.com/montesjoseines24-lang/Soe-app.git
cd Soe-app

# Instala y corre
npm install
npm start
```

### Opción 3: Deploy Online
```bash
# Build
npm run build

# Opción A: Netlify Drag & Drop
# https://app.netlify.com/drop

# Opción B: Deploy automático (push a GitHub)
```
