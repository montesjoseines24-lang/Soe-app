## 🚀 DEPLOYMENT EN 3 PASOS (COPIAR/PEGAR)

**Usa:** SOE_QUICK_REFERENCE.md

```bash
# PASO 1: Setup
npx create-react-app soe-app
cd soe-app
npm install recharts
# Reemplaza src/App.js con SOE_APP.jsx
npm run build

# PASO 2: GitHub
git init
git add .
git commit -m "SOE"
git remote add origin https://github.com/TU_USERNAME/soe-app.git
git push -u origin main

# PASO 3: Netlify
# https://app.netlify.com
# New site from Git → GitHub → soe-app → Deploy
```
